# Contributions and collaboration

This project is developed with AI assistance. It does not claim that all implementation was independently written by its owner, that standard methods are novel, or that generated explanations demonstrate understanding.

## Attribution

- The owner set the research and publication objectives and the requirement to preserve private data.
- Existing modules and tests were extracted with hashes in [the provenance manifest](source-provenance.json).
- Public examples, publication documentation, the aggregation command and additional tests were prepared with Codex assistance.
- The flat calculator's fixture-builder function is omitted because it depends on the excluded experiment framework. Its calculation function is retained. Package initializers avoid private-workspace imports.
- Historical review judgments and experimental results remain distinct from checks performed for this edition.

The allocation of original implementation and research decisions has not been independently audited. Describe specific contributions when discussing a case, and demonstrate understanding through a worked reconstruction.

## Concrete collaboration opportunities

1. Trace a field from source meaning and units to calculation and interpretation. Identify a wrong binding the current controls could accept.
2. Design a revision-impact task with an equally capable flat-table baseline. Predefine success and cost measurements.
3. Challenge interval overlap, missing end dates and first availability using synthetic records.
4. Prepare a forecast case and diagnose a model failure without selecting only favorable companies or changing the baseline after seeing results.

A proposed change should state the question, minimal example, expected behavior and a test that could reject the proposal. Do not upload credentials, account information, licensed rows, private traces or documents without an established redistribution basis.

No open-source license grant is included. Licensing can be selected explicitly after ownership and reuse terms are reviewed; this repository does not grant rights to upstream datasets.
